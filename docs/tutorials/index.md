## 推荐阅读顺序

每章建议按照以下结构阅读：

1. 先看本章要解决的真实问题。
2. 沿着一次请求追踪调用链。
3. 阅读最小实现，而不是一次浏览整个包。
4. 对照 Hermes 的同类实现，理解教学版省略了什么。
5. 修改一个参数或策略，运行测试观察变化。

!!! note "关于 Hermes 对照"
    Hermes 代码链接应固定到具体 commit。教程解释设计差异，不复制生产项目中
    与当前教学点无关的代码。
