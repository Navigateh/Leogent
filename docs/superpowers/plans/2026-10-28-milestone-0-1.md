# Leogent Milestone 0-1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the installable Leogent Python package, its CLI skeleton, the Milestone 1 domain models, and layered JSON configuration loading.

**Architecture:** Keep `domain` independent from infrastructure and `config` independent from runtime. Pydantic models enforce serialization and validation at package boundaries; a small Typer CLI proves the console entry point without implementing later runtime behavior.

**Tech Stack:** Python 3.11+, uv, Pydantic 2, Typer, platformdirs, pytest, Ruff, Pyright, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-28-leogent-phase1-design.md`

## Global Constraints

- Display name is `Leogent`; Python import package is `leogent`; CLI command is `leogent`.
- Default data-directory override is `LEOGENT_HOME`.
- Provider secrets are referenced through environment variable names and are never stored in JSON.
- Milestone 0 uses Python 3.11 or newer and must run with `uv run`.
- Milestone 0/1 do not implement providers, MCP, Agent Loop, sessions, memory storage, compression, or TUI behavior.
- Milestone 0/1 do not implement a sandbox or permission boundary.
- Do not push to the remote repository.

```python
def load_config(
    global_path: Path | None,
    project_path: Path | None,
    environ: Mapping[str, str] | None = None,
) -> AppConfig:
    merged = _merge_mappings(
        _read_json_mapping(global_path),
        _read_json_mapping(project_path),
    )
    environment = os.environ if environ is None else environ
    if provider := environment.get("LEOGENT_DEFAULT_PROVIDER"):
        merged["default_provider"] = provider
    return AppConfig.model_validate(merged)
```
