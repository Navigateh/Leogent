# Leogent Milestone 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add normalized model provider protocols, OpenAI-compatible and Anthropic HTTP providers, stream parsing, a scripted mock provider, and a single-turn `leogent run --no-tui` command.

**Architecture:** Provider implementations translate the infrastructure-independent `ModelRequest` into vendor payloads and translate vendor responses back into `ModelResponse` or `ModelChunk` values. HTTP providers share a validation layer and accept an injected `httpx.Client`, which keeps request mapping, errors, and streaming deterministic in tests.

**Tech Stack:** Python 3.11+, Pydantic 2, HTTPX, Typer, pytest, Ruff, Pyright.

**Spec:** `docs/superpowers/specs/2026-10-28-leogent-phase1-design.md`

## Global Constraints

- The Python import package is `leogent` and the CLI is `leogent`.
- Provider secrets are read from environment variables and never logged.
- Anthropic uses its native Messages API; OpenAI-compatible covers cloud and local HTTP servers.
- Transformers execution remains in Milestone 10 and must produce a clear configuration error when selected.
- Milestone 2 performs exactly one model request. It does not execute tool calls or implement an Agent Loop.
- Tests use `httpx.MockTransport`; real API tests are marked `live`.
- All work stays on `codex/milestone-2`; do not push.
